# Product model — حبر · Ink

Two kinds of practice. Same paper, different goals.

## Why two modes?

Many learners want **Arabic** so they can read Qur’an, duas, and everyday words.  
Others want **calligraphy** — the art of the pen (khaṭṭ).

Those are related but **not the same class**:

| | **Writing · كتابة** | **Calligraphy · خط** |
|--|---------------------|----------------------|
| Goal | Learn the alphabet and readable hand | Train beauty, proportion, pen feel |
| Core lesson | Letter shapes **by position** in a word | Style personality (naskh, thuluth…) |
| Model | Clear school Naskh | Style-aware fonts + freehand |
| Success | “I can write ب at start / middle / end” | “My line feels balanced and intentional” |

## Writing mode

1. Pick a letter  
2. Practice **Alone / Start / Middle / End**  
3. **Connect** (start → middle → end joined)  
4. Optional practice words  
5. Trace ghost · Show me · freehand  
6. Eraser for small fixes (not only clear-all)

No keyboard. Naskh only. Ghost on by default.

## Calligraphy mode

1. Choose a style  
2. Type or pick a word  
3. Pen size, plain or lined paper  
4. Draw freely with pen / eraser / undo  

## Shared paper tools

Pen · Eraser · Undo · Clear all · Show me · Ghost  

Always under the paper so phone and iPad users can reach them while practicing.
